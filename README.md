# 크리스마스 광장

눈 내리는 유럽풍 밤 광장을 걸어 다니는 웹 픽셀 공간.

바로 실행: https://dlacogus.github.io/christmas-ground/ (방향키/WASD로 이동, 모바일은 바닥 탭)

## 실행 방법

Node.js가 필요하다.

```bash
npm install
npm run dev     # 개발 서버 실행 후 브라우저에서 표시된 주소로 접속
npm run build   # 타입 검사 + dist/ 에 빌드
npm test        # 테스트 (vitest)
npm run deploy  # 빌드해서 gh-pages 브랜치에 올림 → GitHub Pages에 반영 (1~2분)
```

작업 규칙은 [CLAUDE.md](CLAUDE.md) 참고.
